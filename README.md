# Рецептурный справочник
Учебный проект по командной разработке ПО. Вариант 4. Приложение на Flask показывает рецепты, состав и порядок приготовления. Поиск по части названия ингредиента помогает выбрать блюдо из доступных продуктов.

## Запуск
Из корня проекта в окружении Python 3.10+ выполните:
```sh
python -m pip install -r requirements.txt
python -m flask --app app run
```
Откройте http://127.0.0.1:5000. Проверки: `python -m unittest discover -s tests -v`.

## Порядок работы
Каждая задача начинается от актуальной main. Ветки feature/recipes, feature/ingredients и feature/templates отвечают за каталог, поиск и оформление. Коммиты оформляем как `тип(область): действие`. Автор публикует ветку, открывает pull request и указывает, как проверить изменение. Второй участник проверяет diff, тесты и обе страницы. Слияние выполняем после одного независимого одобрения. После слияния рабочую ветку можно удалить.

Если две ветки изменили шапку templates/base.html, автор второй ветки вливает main в свою ветку, объединяет ссылку на каталог и ссылку на поиск, проверяет наследование Jinja и запускает тесты. Затем отправляет исправление на повторное ревью.
